## Quick Start

### Install dependencies

```bash
npm install
```

### Configure environment

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
OPENAI_API_KEY=your_api_key_here
```

### Run

```bash
node scripts/atlas-cli.js
```

or

```bash
node scripts/atlas-server.js
```

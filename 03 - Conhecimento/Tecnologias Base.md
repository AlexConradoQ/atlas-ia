# Tecnologias Base

## Obsidian

Função:
Sistema principal de organização do cérebro da IA.

Objetivo:
Guardar memória, projetos, ideias, conhecimento e documentação.

---

## GPT

Função:
Raciocínio, planejamento, respostas organizadas e assistência geral.

Uso futuro:
- Planejamento
- Programação
- Explicações
- Arquitetura
- Continuidade de projetos

---

## Gemini

Função:
Leitura de grandes contextos, arquivos e suporte multimodal.

Uso futuro:
- Análise de documentos
- Organização
- Contexto longo
- Apoio à memória

---

## Claude

Função:
Auxílio avançado em programação e arquitetura de software.

Uso futuro:
- Revisão de código
- Estruturação de sistemas
- Automação
- Desenvolvimento técnico

---

## React

Função:
Criação de interfaces modernas.

Uso futuro:
- Sites
- Painéis
- Sistemas
- Dashboards

---

## Node.js

Função:
Back-end e APIs.

Uso futuro:
- Sistema da IA
- Integrações
- Banco de dados
- APIs

---

## PostgreSQL

Função:
Banco de dados principal.

Uso futuro:
- Memória persistente
- Usuários
- Projetos
- Histórico

---

## Supabase

Função:
Back-end rápido com autenticação e banco integrado.

Uso futuro:
- Login
- Banco
- APIs
- Armazenamento

---

# Objetivo Geral

Todas as tecnologias devem trabalhar juntas para criar uma IA persistente e evolutiva.
